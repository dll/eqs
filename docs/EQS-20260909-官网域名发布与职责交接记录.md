## 3. 内部实用优先的协作口径

EQS 当前按公司内部实用系统推进，允许 CEO、CTO、CDO 采用轻量、灵活、快速迭代的协作方式，不以完整流程手续作为系统开始使用的前置条件。

但“灵活”不等于跳过最低安全与可追溯要求。以下底线仍保留：

- 不在文档或 Git 中记录真实凭据；
- 涉及真实资金、支付、短信、外呼、签约、客户隐私的数据操作，必须明确风险并由相应负责人确认；
- 生产变更、数据库迁移、服务重启等操作须保留操作者、时间、版本和结果记录；
- 对外域名可用性、官网公开内容和客户承接数据需避免敏感信息泄露；
- 先采用可回滚的最小变更，出现异常立即记录并恢复。

该口径适用于当前内部可用性阶段；系统进入正式对外交付、规模化获客或涉及真实交易后，再补齐相应审查与验收要求。
