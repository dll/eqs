# EQS 用户与竞品分析

> 文档版本：V1.0
> 创建日期：2026-08-12
> 分析基线：PRD-v10.0、SAR-v6.0、当前代码实现（提交 29134b9）
> 分析方式：实际用户（甲方/服务方/平台方）视角 + 行业竞品对比（广联达数字新咨询、工程咨询招标网、八戒工程等）

---

## 1. 执行摘要

EQS 已具备"中小项目敏捷交易 + AI 辅助决策 + 三角色闭环"的完整骨架，在工程服务垂直领域有清晰差异化空间。主要短板集中在：**资金托管/电子签未闭环（Mock）**、**服务决策信息不足（无案例/评价分布）**、**派单推荐弱（仅信用）**、**增值服务未落地**。

已按优先级实施第一项 P1 改进（服务超市增强：服务商经营数据与评价分布），其余项列入计划。

## 2. 从实际用户视角分析

### 2.1 甲方（需求方 / 业主）

#### 优点

| # | 优点 | 说明 |
|---|------|------|
| 1 | 发单流程完整 | 创建→附件上传→智能服务清单→编辑→删除/下架，闭环度高 |
| 2 | 报价透明 | 可看全量报价排名，中选生成订单，节点验收+资金流水可视化 |
| 3 | 进度透明 | 进度看板 + AI 单项目分析，像"查快递"一样跟踪 |
| 4 | 权益保障 | 争议流程（证据→专家→结案）+ 评价信用体系 |

#### 不足

| # | 不足 | 影响 | 优先级 |
|---|------|------|--------|
| 1 | 支付/资金托管仍为 Mock | "节点验收后付款"未闭环，资金安全承诺无法兑现 | P0 |
| 2 | 服务超市缺案例/成交/对比信息 | 选服务方凭报价和信用，决策信息不足 | P1 |
| 3 | 无实时触达（推送/短信） | 接单/中选等关键节点靠手动刷新 | P2 |

### 2.2 服务方（工程师 / 公司）

#### 优点

| # | 优点 | 说明 |
|---|------|------|
| 1 | 资质管理完整 | 提交/扫描件上传/编辑/删除/AI 辅助审核 |
| 2 | 接单链路完整 | 报价与撤回、我的报价、接单通知、交付模板清单校验 |
| 3 | 过程凭证完整 | GPS 打卡、交付物版本化、按节点结算+佣金透明 |

#### 不足

| # | 不足 | 影响 | 优先级 |
|---|------|------|--------|
| 1 | 派单推荐弱 | 仅按信用分排序，无"地理位置+资质+历史评价"多维匹配（PRD"3 秒推荐"未实现） | P1 |
| 2 | 无企业主页/案例沉淀 | 成交案例、评分分布、服务记录不能沉淀为获客资产 | P1（部分已实施） |
| 3 | 无 CAD/图纸在线预览 | 在线协作只有批注，无法看图 | P1 |

### 2.3 平台方（运营 / 风控）

#### 优点

| # | 优点 | 说明 |
|---|------|------|
| 1 | 全量管理 | 用户/项目/订单/争议/资质/佣金/配置/审计全量管理 |
| 2 | AI 能力 | 全量项目分析、争议三专家自动评审、资质 AI 辅助审核 |
| 3 | 安全基线扎实 | P0=0、AES-256 加密、CORS 白名单、凭据 .env 化、systemd 加固 |

#### 不足

| # | 不足 | 影响 | 优先级 |
|---|------|------|--------|
| 1 | 数据驱动弱 | 无运营看板（转化漏斗/服务商活跃度/区域分布） | P2 |
| 2 | 增值服务未落地 | 会员、保险、打印邮寄、造价指数（PRD 第五阶段商业模式） | P2 |
| 3 | 无 SLA/告警/值班 | 99.9% 可用性无法证明 | P2 |

## 3. 竞品对比

| 维度 | EQS | 广联达数字新咨询 | 工程咨询招标网 | 八戒工程 |
|------|-----|-----------------|---------------|---------|
| 定位 | 中小工程交易协作平台 | 咨询企业作业平台 | 招标信息聚合 | 综合服务交易 |
| 交易闭环 | ✅ 发单→结算→评价 | 🔶 偏作业工具 | 🔶 只做信息 | ✅ 有交易 |
| 专业工具 | ⚠️ 无计价/算量 | ✅ 云计价/算量强 | - | - |
| 数据服务 | ⚠️ 规划中 | ✅ 指标网/广材网 | ✅ 招标数据 | - |
| 资金托管 | ⚠️ Mock | - | - | ⚠️ 弱 |
| AI 能力 | ✅ 分析/审核/清单 | 🔶 智能组价 | - | - |
| 多端 | ✅ H5/小程序/App/PC | ✅ | ✅ | ✅ |

### 差异化结论

- 广联达太重（企业级工具 + 数据服务），不适合中小业主快速发单；
- 招标网只做信息聚合，不提供交易闭环；
- 八戒工程偏综合服务，工程垂直深度不足；
- **EQS 机会**：中小项目敏捷交易 + AI 辅助决策 + 资金担保，走"轻量垂直平台"路线。当前最大短板是**工具化（计价/预览）和数据服务弱、资金未闭环**。

## 6. 结论

EQS 的产品骨架（三角色闭环、AI 能力、安全基线、多端）在同规模竞品中具备差异化竞争力。要兑现"资金担保、3 秒推荐、进度透明"的核心价值主张，需优先完成 P0 外部通道接入（支付/电子签），并持续推进 P1 决策信息增强（已启动）与派单智能化。

**当前评级：可演示/试运行级；P0 通道接入后进入公测。**
