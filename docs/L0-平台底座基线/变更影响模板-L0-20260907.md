## 附：门禁最小必答（简化版，用于快速 PR Checklist）

对**每一个**平台底座改动，CTO 门禁前至少确认以下 3 项为 **NO / 否**：
1. 未增删改 `main.go` 路由注册行 且（如需新增端点）未涉红区；
2. 未增删改 `model/db.go` AutoMigrate 清单 / 红区模型字段与落库值；
3. 未改动既有资金/dispute/AI handler 逻辑与交易状态机迁移值。

三项不全为否 → **暂停合入，走完整影响清单 + CTO 门禁**。
