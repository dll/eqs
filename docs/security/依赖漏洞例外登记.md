# EQS 生产依赖漏洞例外登记（P1-15）

> **文档版本**：V1.0
> **创建日期**：2026-08-11
> **登记原因**：SAR-v5.0 P1-15 要求"生产依赖 8 个高危漏洞升级、缓解或正式例外"

---

## 1. 审计结论

`pnpm audit --prod`（client 包）：**19 个漏洞**（1 low / 10 moderate / 8 high）。

**全部通过 `@dcloudio/*`（Uni-app 工具链）间接引入，均为构建期工具**，不进入生产运行时产物。

## 2. 高危漏洞明细（8 个）

| 包 | 漏洞 | 引入链 | 风险面 |
|----|------|--------|--------|
| jpeg-js <0.4.4 | Infinite loop DoS | @dcloudio/uni-mp-weixin→jimp | 构建期图片处理 |
| @intlify/core-base <9.1.11 | Prototype Pollution | @dcloudio/uni-cloud→uni-cli-shared | 构建期 i18n 编译 |
| @intlify/message-resolver | Prototype Pollution | 同上 | 构建期 |
| ws <8.21.0 | Memory DoS | @dcloudio/uni-mp-weixin | 构建期 websocket |
| vite ≤6.4.2 | fs.deny bypass | uni-app-vite→vite | dev server（非生产） |
| adm-zip <0.6.0 | 4GB 内存分配 | uni-cli-shared | 构建期压缩 |
| postcss ≤8.5.11 | 任意文件读 | uni-nvue-styler | 构建期 CSS 编译 |
| postcss ≤8.5.17 | Path Traversal | 同上 | 构建期 |

## 3. 例外理由（正式风险接受）

1. **运行时不可达**：上述包仅用于**编译构建**（H5/小程序/App 资源生成），打包产物不包含这些运行时库，生产环境用户无法触发相关代码路径。
2. **框架版本锁定**：受 `@dcloudio/uni-app-plus` 等版本锁定（须匹配 `3.0.0-5020320260806002`），独立升级这些传递依赖会破坏 uni 构建（已验证 overrides 不生效且 peer 冲突）。
3. **攻击面限制**：vite 相关漏洞仅影响**开发服务器**（`dev server.fs.deny`），生产使用 `vite build` 静态产物，不暴露 dev server。
4. **缓解措施**：CI 构建在隔离 runner 执行；构建输入为受控源码，无不可信第三方文件输入。

## 4. 例外有效期与复核

- **复核频率**：每季度 + DCloud 发布新 uni 版本时。
- **解除条件**：
  - DCloud 升级 `@dcloudio/*` 修复相关依赖；或
  - 迁移至新框架版本（如 uni-app x）；或
  - 改用自定义构建管线绕开受影响工具。
- **登记人**：项目负责人 / AI Assistant
- **审批**：待安全负责人签字（SAR-v5.0 第 10.1 阶段出口要求）
