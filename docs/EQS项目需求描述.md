## 一、项目概述

### 1.1 项目定位

工程快捷服务（Engineering Quick Service，简称 EQS）是专为工程服务业打造的**一站式智慧交易与协作平台**，连接设计、造价、地勘、监理四大核心服务商，为业主提供"发单—匹配—签约—交付—结算"的全流程线上化服务。

### 1.2 核心价值主张

- **对甲方/业主**：像"点外卖"一样简单、快速比价、合规招标、全程透明、进度可控。
- **对服务方**：像"滴滴抢单"一样，量分发、省去商务成本、快速结算、信用背书。
- **对平台方**：规则制定、资金监管、纠纷仲裁、数据沉淀。

### 1.3 差异化定位

中小项目敏捷交易 + AI 辅助决策 + 资金担保，走"轻量垂直平台"路线。区别于企业级作业工具（广联达）、招标信息聚合（招标网）、综合服务交易（八戒工程），聚焦工程咨询垂直领域的完整交易闭环。

### 1.4 业务闭环

```
发布需求 → 匹配/抢单 → 线上签约 → 过程交付（资料上传/审批）
→ 成果确认 → 按节点/进度结算 → 评价与信用沉淀
```

## 四、功能需求

### 4.1 智能发单（甲方）

- 标准化表单发布需求：类型（造价/监理/地勘/设计）、标题、预算区间、地址、描述、附件（≤50MB）。
- **智能服务清单**：按服务类型自动生成标准交付清单（如造价：工程量清单 GB50500 / 招标控制价编制说明 / 计价软件源文件 / 主要材料询价单）。
- **项目附件上传**：`POST /project/upload`，支持 dwg/dxf/pdf/jpg/png/doc/xls（≤50MB），本地存储 + 文件登记。
- 项目完整 CRUD：创建 / 列表 / 详情 / 编辑（已有订单时锁定预算与类型）/ 删除（无业务物理删除，有业务下架）。
- 规则：项目金额 ≥50 万需上传立项批文；同一项目最多邀请 5 家服务商。

### 4.2 服务超市（甲方）

- 按服务类型分类展示服务商（造价/监理/地勘/设计）。
- **服务商主页**：公司名、信用分、资质证书、经营数据（签约订单 / 已完成 / 评价数 / 1~5 星分布 / 近期评价）。
- 智能派单推荐：返回综合匹配分（资质匹配 +60、信用折算 40）与资质匹配标记。

### 4.3 报价与竞价（双方）

- 服务方报价：金额 / 工期 / 说明；截止前可撤回；我的报价列表。
- 甲方查看报价排名（服务方仅见脱敏排名）、中选报价。
- 中选后自动生成订单并通知服务方（接单通知）。

### 4.4 订单与里程碑（双方）

- 订单状态机：0 待签约 → 1 进行中 → 2 待验收 → 3 已完成 → 4 纠纷中 → 5 下架 → 6 已取消。
- 甲方设置付款里程碑（比例合计 100%），生成合同、双方签署。
- 订单 CRUD：详情 / 更新（备注 / 期望工期 / 未签约可调金额）/ 取消（仅未签约）。

### 4.5 合同管理（双方）

- 合同模板库；按订单生成合同（合同号 EQS-YYYY-####）；签署；下载。
- 电子签通道当前为 Mock（验签与接口已就绪，待服务商签约）。

### 4.6 支付与结算（双方）

- 按里程碑节点结算（Mock 通道），生成资金流水。
- **全部里程碑结算完成后订单自动推进已完成（status=3）**，项目同步完成，触发信用分重算。
- 资金流水 / 余额查询；支付回调验签（HMAC + 订单关联 + 金额校验 + 时间戳防重放 + 幂等）。

### 4.7 交付与打卡（服务方）

- 交付物：按里程碑上传（文件名 / URL / 版本递增），甲方验收 / 驳回。
- **标准交付模板**：列表 / 详情 / 必交清单勾选校验。
- GPS 打卡：经纬度加密存储、距离超阈值标记异常、打卡记录与履约时长估算。

### 4.8 资质管理（服务方 + 平台方）

- 服务方提交资质：类型 / 证书号（AES-256-GCM 加密）/ 等级 / 范围 / 发证机关 / 签发日期 / 有效期 / **扫描件附件**。
- 资质 CRUD：提交 / 列表（状态过滤）/ 详情 / 编辑（已通过不可改）/ 删除（已通过不可删）。
- **扫描件上传**：jpg/png/pdf ≤10MB，本地存储 + 文件登记。
- **平台审核**：通过条件门禁（证书号 / 发证机关 / 有效期 / 附件完整）+ **AI 辅助审核**（大模型或规则降级，输出风险与建议）。

### 4.9 纠纷与仲裁（双方 + 平台方）

- 发起争议（原因 / 诉求，节点资金冻结）→ 上传证据 → **三专家自动评审** → 专家意见 → 结案（款项解冻）。
- 争议 CRUD：创建 / 详情 / 更新（发起人补充）/ 结案。
- 平台方：争议详情、指派专家（自动/手动）、结案。

### 4.10 消息与通知（全端）

- 站内消息：发送 / 列表（会话双向）/ 详情 / 删除 / 已读。
- 系统通知：列表 / 未读数 / 已读；业务自动触发（中选 / 取消 / 专家指派 / 争议）。
- **未读角标**：客户端"我的"页消息入口红色角标。

### 4.11 评价与信用（双方 + 平台方）

- 订单完成后双方互评（1~5 星 + 内容），同一订单同向仅一次。
- **信用联动**：评价 / 交付准时 / 纠纷次数按权重重算（幂等）。
- 按项目查看评价（甲方 / 服务方 / 管理员）。

### 4.12 平台运营管理（平台方）

- 用户：列表 / 详情（项目/订单/资质/评价统计）/ 启用禁用（禁止操作自身）。
- 项目：全量监管 / 编辑 / 下架。订单：全量 / 取消。流水：全量。
- **运营看板**：用户结构、项目/订单状态分布、转化漏斗（发布→中选→完成）、近 7 天活跃服务商。
- 佣金：列表 / 收取（幂等）。配置中心 CRUD。版本发布。审计日志。演示数据管理（seed/clean/toggle/status）。

## 六、非功能性需求

### 6.1 界面与体验

- 统一 UI 设计系统：工程蓝 `#2563EB` × 科技青 `#06B6D4` × AI 紫 `#8B5CF6`，玻璃拟态、渐变光晕、AI 面板。
- 主题：print / dark / light 三套 + 项目维度主题。
- 国际化：中 / 英（Admin + Client）。
- 多端：H5 / 小程序 / App / PC。

### 6.2 性能与可用性

- 列表分页保护（size ≤100）、查询索引。
- 优雅停机（SIGTERM，最多 10s 等待）、systemd 守护自动重启、健康检查端点。
- 版本检查与更新（客户端）。

### 6.3 安全与合规

- 认证：JWT HS256 白名单 + 用户状态实时校验 + 角色以数据库为准。
- 授权：对象级授权（订单/项目/争议）+ 管理端 RequireAdmin + 禁止操作自身。
- 数据：AES-256-GCM 敏感字段加密（证书号/经纬度）、手机号脱敏、备份文件 600。
- 接口：CORS 白名单（生产域名 + 同源）、错误信息收敛（生产不泄露内部细节）、上传类型/大小限制、支付回调验签。
- 部署：systemd 非 root + NoNewPrivileges/ProtectSystem、nginx 安全头、凭据 `/opt/eqs/.env`(600) EnvironmentFile 加载。
- 启动校验：生产拒绝弱密钥、必填 `DATA_ENCRYPTION_KEY`。

- 数据库每日备份（gzip + 7 天保留 + 权限 600）。

## 八、接口设计

- 当前 **116 条路由**：公开 12 + 登录态 84 + 管理 20。
- 分组：Auth、Project、Bid、Order、Contract、Payment、Dispute、Qualification、File、Message、Review、Attendance、Admin。

## 九、部署与运维

### 9.1 部署架构

- 腾讯云 CVM（`129.211.223.113`）；Caddy 提供 `eqs-chzu.tech` 自动 HTTPS，转发至 Nginx:8091；Nginx 按路径分发 /admin、/h5、/api。
- 后端 systemd 服务（eqs 用户、加固配置），监听 8090（仅本机）。
- MySQL/Redis 仅监听 127.0.0.1，公网不暴露。

### 9.2 CI/CD

- CI：GitHub Actions（测试 / 构建 / 覆盖率门禁）。
- CD：CI 成功后自动部署（后端二进制替换 + 静态资源同步 + 服务重启）。
- 部署产物：后端 Linux 交叉编译二进制、Admin dist、Client H5 dist。

### 9.3 备份与监控

- 每日 02:30 cron 全量备份（mysqldump + gzip + 校验 + 7 天保留）。
- 健康检查 `/health`；运行时统计端点（管理端）。
