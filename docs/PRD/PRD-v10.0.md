## 1. 项目概述

### 1.1 产品定位

工程快捷服务 (EQS) —— 专为工程服务业打造的"一站式智慧交易与协作平台"，连接设计、造价、地勘、监理四大核心服务商，为业主提供"发单-匹配-签约-交付-结算"的全流程线上化服务。

### 1.2 业务闭环

发布需求 → 匹配/抢单 → 线上签约 → 过程交付(资料上传/审批) → 成果确认 → 按节点/进度结算 → 评价与信用沉淀

### 1.3 角色定义

| 角色 | 定义 | 平台端 |
|------|------|--------|
| 甲方（需求方） | 建设单位、施工单位、个人业主 | 用户端 H5/小程序 |
| 服务方 | 造价事务所、地勘院、监理公司、设计院、独立工程师 | 用户端 H5/小程序 |
| 平台方 | 规则制定、资金监管、纠纷仲裁、数据沉淀 | 管理后台 PC |

### 1.4 V10.0 目标

在 V9.0 完成核心模块 CRUD 补齐的基础上，V10.0 按**角色视角**完整化：确保甲方、服务方、平台方三方能各自闭环完成本角色全部职责，输出**三角色功能矩阵**作为验收依据。

```

GET  /api/v1/admin/users/:id       # 平台方：用户详情（含项目/订单/资质/评价统计）
```

| 端 | 操作 | 说明 |

### 6.3 角色权限复核（V10.0 验证通过）

- 甲方：全部发单/报价/订单/合同/支付/交付/评价/争议/消息操作，均校验"项目创建者"身份；
- 服务方：资质/报价/交付/打卡/争议/消息操作，均校验"本人"身份；
- 平台方：所有 /admin/* 路由统一 RequireAdmin（user_type=3），且用户状态接口禁止操作当前登录账号。
