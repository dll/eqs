## 1. 项目概述

### 1.1 产品定位

工程快捷服务 (EQS) —— 专为工程服务业打造的"一站式智慧交易与协作平台"，连接设计、造价、地勘、监理四大核心服务商，为业主提供"发单-匹配-签约-交付-结算"的全流程线上化服务。

### 1.2 业务闭环

发布需求 → 匹配/抢单 → 线上签约 → 过程交付(资料上传/审批) → 成果确认 → 按节点/进度结算 → 评价与信用沉淀

### 1.3 角色定义

- **需求方（甲方）**：建设单位、施工单位、个人业主。
- **服务方**：造价事务所、地勘院、监理公司、设计院、独立工程师。
- **平台方**：规则制定、资金监管、纠纷仲裁、数据沉淀。

### 1.4 范围说明（V9.0）

V8.0 已形成可构建、可部署、可演示的完整工程；V9.0 聚焦三类补强：
1. **CRUD 完整性**：对照初始需求中"数据可维护"隐含要求，补齐项目/资质/订单/消息/争议/评价等核心模块的编辑、删除、取消、详情操作；
2. **资质可信度**：扫描件附件备份、必要字段、AI 辅助审核（对应初始需求"资质审核：人工+OCR识别"与"挂靠风险"控制）；
3. **界面与安全**：全新设计系统 + 生产安全加固。

## 4. V9.0 新增：资质模块增强

> 对应初始需求：C 端"资质审核：人工+OCR识别，验证营业执照、资质证书、人员证书"；第四阶段"挂靠风险：强制上传社保记录+注册证书"。

### 4.1 必要字段（模型扩展）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| qualification_type | string | ✅ | 资质类型 |
| certificate_no | string(加密) | ✅ | 证书编号（AES-256-GCM 存储） |
| level | string | - | 等级（甲级/乙级等） |
| scope | string | - | 专业范围 |
| **issuing_authority** | string | ✅(审核通过需) | 发证机关 |
| **issue_date** | datetime | - | 签发日期 |
| **valid_from / valid_to** | datetime | ✅(valid_to) | 有效期起止（过期拒收） |
| **evidence_file_id** | uint | ✅(审核通过需) | 扫描件附件（登记 project_files） |
| review_comment | string | - | 审核意见/驳回原因 |

### 4.2 扫描件上传（附件备份）

- 接口：`POST /api/v1/qualification/upload`（multipart/form-data, `file` 字段）
- 限制：jpg/jpeg/png/pdf，≤10MB
- 存储：本地 `uploads/qualifications/YYYYMM/` + `project_files` 表登记（上传者/原名/类型/路径）
- 用途：服务方上传证书扫描件作为附件备份；管理员审核时可追溯；资质提交时关联 `evidence_file_id`

### 4.3 管理员审核增强

**自动通过条件（硬性门禁）**——不满足则拒绝通过并提示缺失项：
1. 证书编号非空；
2. 发证机关非空；
3. 有效期未过期（valid_to ≥ 当前时间）；
4. 已上传扫描件附件。

**AI 辅助审核**：
- 配置 `ZHIPU_API_KEY` 时调用大模型对资质信息做风险评估（输出 risk: low/medium/high + suggestion）；
- 未配置时按规则降级（校验结果生成建议）；
- 审核后记录 `verification_method=ai`、`review_comment="AI建议:…。人工备注:…"`，审计日志含 ai_risk。
