## 一、项目概述

### 1.1 产品定位

工程快捷服务（Engineering Quick Service，简称 EQS）是专为工程服务业打造的**一站式智慧交易与协作平台**，连接设计、造价、地勘、监理四大核心服务商，为业主提供"发单—匹配—签约—交付—结算"的全流程线上化服务。

### 1.2 核心价值主张

- **对甲方/业主**：像"点外卖"一样简单、快速比价、合规招标、全程透明、进度可控。
- **对服务方（工程师/公司）**：像"滴滴抢单"一样，量分发、省去商务成本、快速结算、信用背书。
- **对平台方**：做规则制定、资金监管、纠纷仲裁、数据沉淀。

### 1.3 适合场景

新建工程、旧改项目、临时签证、小型工程签证、零星维修预算、临时监理等，均可快速发布需求，获得专业、透明、高效的工程服务。

### 1.4 差异化定位

中小项目敏捷交易 + AI 辅助决策 + 资金担保 + 工具化（计价/CAD预览），走"轻量垂直平台"路线。

## 二、业务闭环

### 2.1 核心业务闭环

```
发布需求 -> 匹配/抢单 -> 线上签约 -> 过程交付(资料上传/审批)
-> 成果确认 -> 按节点/进度结算 -> 评价与信用沉淀 -> 案例沉淀/会员留存
```

### 2.2 角色定义

| 角色 | 定义 | 平台端 |
|------|------|--------|
| 甲方（需求方） | 建设单位、施工单位、个人业主 | 用户端 H5/小程序/App |
| 服务方 | 造价事务所、地勘院、监理公司、设计院、独立工程师 | 用户端 H5/小程序/App |
| 平台方 | 规则制定、资金监管、纠纷仲裁、数据沉淀 | 管理后台 PC + H5 管理端 |

## 三、产品功能模块需求

### 3.1 用户端（甲方）——发单与监控

#### 3.1.1 智能发单

- 甲方标准化表单发布需求：类型（造价/监理/地勘/设计）、标题、预算区间、地址、描述、附件。
- **智能服务清单**：按服务类型自动识别并生成标准化服务需求清单（如造价：工程量清单 GB50500、招标控制价编制说明、计价软件源文件、主要材料询价单）。
- **项目附件上传**：支持 dwg/dxf/pdf/jpg/png/doc/xls（≤50MB），作为立项批文等附件备份。
- **立项批文强制校验**：项目预算上限 ≥50 万元必须上传立项批文附件（表单条件提示 + 服务端校验）。
- 项目完整管理：创建、列表、详情、编辑（有订单时锁定预算与类型）、删除（无业务物理删除，有业务撤销/废除软删除，保留数据积累）。
- 业务规则：同一项目最多邀请 5 家指定服务商。

#### 3.1.2 服务超市

- 按服务类型（造价、地勘、监理、设计）分类展示服务商。
- 服务商主页：公司名、信用分、资质证书、经营数据（签约订单、已完成、评价数、1~5 星评分分布、近期评价）、**服务案例（企业案例沉淀）**。
- **智能派单推荐**：基于地区、资质等级、历史评价生成综合推荐（资质匹配 + 信用分加权 + 会员加权）。

#### 3.1.3 进度看板

- 类似"物流跟踪"，实时显示服务方已接单、勘察中、报告编制中、审核中、已交付各阶段。
- 单项目进度时间线 + 平台方甘特图/看板视图（含阶段时间与提前/按时/滞后状态）。

#### 3.1.4 资金托管与结算

- 费用按节点（如提交初稿付 30%，终稿付 70%）释放，保障双方利益。
- **资金托管台账**：每笔结算释放、争议冻结、结案解冻自动记账，参与方可查订单托管明细（托管总额/已释放/冻结/余额），平台方可对账（全量台账），真实通道接入前 Mock 通道资金同样可对账、可审计。
- 节点验收通过后结算，全部节点结算完成订单自动完成。

### 3.2 服务端（服务方）——接单与执行

#### 3.2.1 智能派单

- 基于地理位置（本地化服务）、资质等级、历史评价自动推送项目；会员服务方额外加权。
- 推荐结果含综合匹配分（match_score）与资质匹配标记。

#### 3.2.2 抢单/竞价

- 服务方对公开项目报价（金额/工期/说明），甲方选择性价比最优。
- 报价管理：提交、撤回（截止前未中选）、我的报价列表。
- 中选后自动生成订单并发送接单通知（站内 + 实时推送 + App 离线推送）。

#### 3.2.3 在线协作

- 文件管理：上传、列表、下载、**在线预览**（图片/PDF 内联；**DXF 服务端自研渲染为 SVG**；**DWG 经第三方引擎适配器转换**，未配置引擎时提示下载）。
- 图纸批注：按页批注、解决/关闭批注。
- 支持 PDF、CAD 文件上传。

#### 3.2.4 考勤打卡

- 针对监理、地勘等需现场服务的人员，支持 GPS 定位打卡，作为服务凭证。
- 经纬度加密存储，距离超阈值标记异常，打卡记录与履约时长估算。

#### 3.2.5 交付与验收

- 按里程碑上传交付物（版本递增），甲方验收或驳回。
- **标准交付模板**：按服务类型预置必交清单，支持勾选校验。
- **计价工具**：工程量清单计价估算（分部分项→措施费→规费→税金→含税总价，费率可配置），服务方报价与甲方预算参考。

#### 3.2.6 企业案例沉淀

- 服务方将**已完成订单**一键沉淀为服务案例（标题/描述/成果图），作为获客资产展示于服务商主页。
- 案例管理：创建（关联已完成订单）、编辑、删除；成果图经签名公开预览链接在未登录页面展示。

### 3.3 管理后台（平台方）——运营与风控

#### 3.3.1 资质审核

- 验证服务方的营业执照、资质证书、人员证书。
- **扫描件上传**（jpg/png/pdf ≤10MB）作为附件备份。
- **AI 辅助审核**：通过条件门禁（证书号/发证机关/有效期/附件完整）+ 大模型风险评估（或规则降级）+ **OCR 扫描件识别**（腾讯云 OCR，审核备注自动附加识别文本）。

#### 3.3.2 合同模板库

- 内置标准化工程服务合同，在线生成电子签章，法律合规。
- 合同模板、按订单生成、双方签署、下载。
- 电子签网关抽象就绪（当前 Mock；真实服务商按统一接口接入）。

#### 3.3.3 结算中心

- 自动生成资金流水，支持按节点结算；**资金托管台账对账**（平台全量台账：冻结/释放/退款）。
- 平台佣金管理：按合同额收取（比例可配置，**会员服务方按等级折扣**），列表与收取。
- 运营看板：用户结构、订单/项目状态分布、成交转化漏斗、近 7 天活跃服务商。

#### 3.3.4 信用评分

- 根据交付准时率、质量评分、纠纷次数进行动态排名（五维权重，幂等重算）。
- 评价与信用联动，评价后自动重算信用分。

#### 3.3.5 用户与运营管理

- 用户列表、详情（项目/订单/资质/评价统计）、启用禁用。
- 项目全量监管、订单全量管理、资金流水全量、**会员列表管理**。
- 系统配置中心、版本发布、审计日志、演示数据管理。

### 3.4 共通能力

#### 3.4.1 消息与通知（含实时推送）

- 站内消息：发送、列表、详情、删除、已读。
- 系统通知：列表、未读数、已读；业务自动触发（中选/取消/专家指派/争议）。
- **站内实时推送**：H5 经 SSE 流实时接收（未读角标与消息页即时刷新），小程序/App 轮询兜底。
- **App 离线推送**：uni-push 按用户手机号别名推送（服务端适配层就绪，未配置时静默降级）。
- 未读角标展示。

#### 3.4.2 评价体系

- 订单完成后双方互评（1~5 星 + 内容），同一订单同向仅一次。
- 按项目/用户查看评价。

#### 3.4.3 纠纷仲裁

- 发起争议（原因/诉求，节点资金冻结并记账）→ 上传证据 → **专家评审团**（三专家自动评审）→ 专家意见 → 结案（款项解冻记账）。
- 平台方指派专家（自动/手动）、争议详情、结案；法定救济声明。

#### 3.4.4 会员体系

- 等级：免费版 / 高级会员（¥99/月）/ 企业会员（¥199/月），开通月数 1-36。
- 权益：平台佣金折扣（高级 9.5 折 / 企业 9 折）、智能派单推荐加权（高级 +5 / 企业 +10）、专属标识、企业会员优先派单。
- 我的会员页：等级状态、有效期、权益列表、开通/续费（当前模拟支付，真实支付通道接入后改为支付网关）。
- 平台端会员列表管理。

## 五、非功能性需求

### 5.1 界面与体验

- 统一 UI 设计系统：工程蓝 `#2563EB` × 科技青 `#06B6D4` × AI 紫 `#8B5CF6`，玻璃拟态、渐变光晕、AI 面板。
- 主题：print / dark / light 三套 + 项目维度主题。
- 国际化：中/英（Admin + Client）。
- 多端：H5、小程序、App、PC。

### 5.2 性能与可用性

- 列表分页保护（size ≤100）、查询索引。
- 优雅停机（SIGTERM）、systemd 守护自动重启、健康检查端点。
- 版本检查与更新（客户端）。

### 5.3 安全与合规

- 认证：JWT HS256 白名单 + 用户状态实时校验 + 角色以数据库为准。
- 授权：对象级授权（订单/项目/争议）+ 管理端 RequireAdmin + 禁止操作自身。
- 数据：AES-256-GCM 敏感字段加密（证书号/经纬度）、手机号脱敏、备份文件 600。
- 接口：CORS 白名单（生产域名 + 同源）、错误信息收敛（生产不泄露内部细节）、上传类型/大小限制、**支付回调验签（微信支付 v3 平台证书 RSA 验签 + AES-GCM 解密）**、公开预览签名（HMAC + 24h 过期）。
- 外部通道凭据：`.env`(600) 加载，未配置自动降级，生产拒绝弱密钥/缺加密密钥启动。
- 部署：systemd 非 root + NoNewPrivileges/ProtectSystem、nginx 安全头、凭据 `.env`(600) 加载。

## 六、技术架构需求

### 6.1 技术栈

| 层 | 技术 |
|----|------|
| 后端 | Go + Gin + GORM + JWT(v5, HS256) + AES-256-GCM |
| 外部通道适配层 | 纯标准库实现（crypto/rsa、crypto/hmac、crypto/aes），无新增第三方依赖 |
| 前端 | Vue3 + Element Plus（Admin）；uni-app Vue3（Client） |
| 数据库 | MySQL（生产）/ SQLite（开发） |
| 缓存 | Redis（验证码/频控） |
| 部署 | 腾讯云 CVM + systemd + Nginx + Caddy |

### 6.2 系统架构

```
Admin PC / H5 / 小程序 / App
        | HTTPS
   Caddy（自动 HTTPS）--> Nginx :8091（/admin /h5 /api 分发）
        | 127.0.0.1:8090
   Go + Gin 后端（systemd 守护）
        |
   MySQL -- Redis
        |
   [外部通道] 腾讯云短信/OCR | 微信支付 v3 | uni-push | CAD 转换服务
```

### 6.3 多端产品形态

| 端 | 技术栈 | 用途 |
|----|--------|------|
| 管理后台 | Vue3 + Element Plus | 平台方运营/风控（PC + H5 管理端） |

- 数据库每日备份（gzip + 7 天保留 + 权限 600）。

## 八、接口需求

### 8.1 接口规模

- 总计 **133 条路由**：公开接口、登录态接口、管理端接口。
- 分组：Auth、Project、Bid、Order、Contract、Payment、Dispute、Qualification、File、Message、Review、Attendance、Admin、Member、Tools。

### 8.2 接口约定

- 认证：`Authorization: Bearer <JWT>`（SSE/公开预览走签名参数）。
- 响应约定：统一数据封装，业务错误返回 error/message/message_key。
- 分页约定：page/size，size 默认 20、最大 100。

## 九、部署与运维需求

### 9.1 部署架构

- 腾讯云 CVM；Caddy 提供域名自动 HTTPS，转发至 Nginx:8091；Nginx 按路径分发 /admin、/h5、/api。
- 后端 systemd 服务（非 root、加固配置、EnvironmentFile 加载凭据），监听本机端口。
- MySQL/Redis 仅监听本机，公网不暴露。

### 9.2 CI/CD

- CI：GitHub Actions（测试/构建/覆盖率门禁 ≥60%）。
- CD：CI 成功后自动部署（后端二进制替换 + 静态资源同步 + 服务重启）。

### 9.3 备份与监控

- 每日定时全量备份（mysqldump + gzip + 校验 + 保留策略）。
- 健康检查端点；运行时统计（接口耗时/P95/错误率）。

## 十一、验收标准

### 11.1 功能验收

- 三角色（甲方/服务方/平台方）全部功能可用，数据链路贯通。
- 多里程碑全部结算后订单自动完成、评价成功、信用分联动。
- 演示数据完整，供演示/测试/培训使用。
- 会员开通/权益联动（佣金折扣、推荐加权）生效；案例沉淀可展示；托管台账可对账。

### 11.2 质量验收

- 后端单元与集成测试通过（含外部通道签名/解密黄金测试）。
- 前端类型检查、代码规范检查通过，构建成功。
- 生产环境演示账号全链路实测通过。

### 11.3 安全验收

- 生产阻断项（P0）为 0。
- 认证授权、数据加密、接口防护、部署加固满足上线要求。
