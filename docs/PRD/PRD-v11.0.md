## 1. 项目概述

### 1.1 产品定位

工程快捷服务 (EQS) —— 专为工程服务业打造的"一站式智慧交易与协作平台"，连接设计、造价、地勘、监理四大核心服务商，为业主提供"发单-匹配-签约-交付-结算"的全流程线上化服务。

### 1.2 核心价值主张

- **对甲方/业主**：像"点外卖"一样简单、快速比价、合规招标、全程透明、进度可控。
- **对服务方**：像"滴滴抢单"一样，量分发、省去商务成本、快速结算、信用背书。
- **对平台方**：规则制定、资金监管、纠纷仲裁、数据沉淀。

### 1.3 差异化定位

中小项目敏捷交易 + AI 辅助决策 + 资金担保，走"轻量垂直平台"路线（区别于广联达企业级工具、招标网信息聚合、八戒综合交易）。


## 5. 功能模块详细说明

### 5.1 智能发单模块（AC-01、AC-02）

- 甲方标准化表单发布需求：类型（造价/监理/地勘/设计）、标题、预算区间、地址、描述、附件（≤50MB）、发布范围。
- **智能服务清单**：按服务类型自动生成标准交付清单（造价：工程量清单 GB50500/控制价编制说明/计价源文件/询价单等）。
- **项目附件上传**：`POST /project/upload`，支持 dwg/dxf/pdf/jpg/png/doc/xls（≤50MB），本地存储 + project_files 登记。
- 项目 CRUD：创建/列表/详情/编辑（有订单锁定预算类型）/删除（无业务物理删除，有业务下架）。
- 业务规则：项目金额 ≥50 万需上传立项批文；同一项目最多邀请 5 家服务商。

### 5.2 服务超市模块（AC-01）

- 按服务类型分类展示服务商（造价/监理/地勘/设计）。
- **服务商主页**：公司名、信用分、资质证书、经营数据（签约订单/已完成/评价数/1~5星分布/近期评价）。
- 智能派单推荐：`GET /project/:id/recommend` 返回 match_score（资质匹配+60、信用折算40）与 qual_matched 标记。

### 5.3 报价与订单模块（AC-02、AC-04）

- 服务方报价：金额/工期/说明；撤回（截止前未中选）；我的报价列表。
- 甲方中选 → 自动生成订单（状态 0 待签约）→ 设置里程碑（比例合计 100%）→ 生成合同 → 双方签署。
- 订单状态机：0待签约 → 1进行中 → 2待验收 → 3已完成 → 4纠纷中 → 5下架 → 6已取消。
- 订单 CRUD：详情/更新（备注/期望工期/未签约调金额）/取消（仅未签约）。
- 接单通知：中选后自动通知服务方。

### 5.4 支付与结算模块（AC-04）

- 节点结算：验收通过后按里程碑结算（Mock 通道），生成资金流水。
- **全部里程碑结算完成后订单自动推进已完成（status=3）+ 项目完成（status=4）**，触发信用分重算。
- 资金流水/余额查询；支付回调验签（HMAC + 订单关联 + 金额校验 + 防重放 + 幂等）。

### 5.5 交付与打卡模块（AC-07、AC-09、AC-12）

- 交付物：按里程碑上传（文件名/URL/版本递增），甲方验收/驳回。
- 标准交付模板：列表/详情/必交清单勾选校验。
- GPS 打卡：`POST /attendance/checkin`（经纬度加密存储、距离校验异常标记）、打卡记录与履约时长估算。

### 5.6 资质模块（AC-05）

- 服务方提交资质：类型/证书号（AES-256-GCM 加密）/等级/范围/发证机关/签发日期/有效期/扫描件附件。
- 资质 CRUD：提交/列表（状态过滤）/详情/编辑（已通过不可改）/删除（已通过不可删）。
- **扫描件上传**：`POST /qualification/upload`（jpg/png/pdf ≤10MB），本地存储 + project_files 登记。
- **管理员审核**：通过条件门禁（证书号/发证机关/有效期/附件完整）+ **AI 辅助审核**（ZHIPU 大模型或规则降级，输出 risk/suggestion）。

### 5.7 合同模块（AC-03）

- 合同模板库；按订单生成合同（合同号 EQS-YYYY-####）；签署（Mock）；下载。

### 5.8 争议模块（AC-11）

- 发起争议（原因/诉求，节点资金冻结）→ 上传证据 → **三专家自动评审**（`POST /dispute/:id/auto-expert`，自动筛选专家并通知）→ 专家意见 → 结案（settlement/agreement/award，款项解冻）。
- 争议 CRUD：创建/详情/更新（发起人补充）/结案。

### 5.9 消息与通知模块

- 站内消息：发送/列表（会话双向）/详情/删除/已读。
- 系统通知：列表/未读数（`GET /notification/unread-count`）/已读；业务自动触发（中选/取消/专家指派/争议）。
- **未读角标**：客户端"我的"页消息入口红色角标。

### 5.10 评价与信用模块（AC-10）

- 订单完成后双方互评（1~5 星 + 内容），同一订单同向仅一次。
- **信用联动**：评价/交付准时/纠纷次数按权重重算（`recalcUserCredit`，幂等）。
- 按项目查看评价（甲方/服务方/管理员）。

### 5.11 运营管理模块（平台方）

- 用户：列表/详情（项目/订单/资质/评价统计）/启用禁用（禁止自操作）。
- 项目：全量监管/编辑/下架。订单：全量/取消。流水：全量。
- **运营看板**：`GET /admin/operations-stats`——用户结构、项目/订单状态分布、转化漏斗（发布→中选→完成）、近7天活跃服务商。
- 佣金：列表/收取（幂等）。配置中心 CRUD。版本发布。审计日志。演示数据（seed/clean/toggle/status）。

## 10. API 设计

- 当前 **116 条路由**（公开 12 + 登录态 84 + 管理 20）。
- 关键分组：Auth、Project、Bid、Order、Contract、Payment、Dispute、Qualification、File、Message、Review、Attendance、Admin。
- 认证：Bearer JWT（HS256，角色以数据库为准，实时校验禁用状态）。
- 权限：对象级授权（canAccessOrder/Project/Dispute）+ RequireAdmin。

## 11. 构建与部署

- CI：GitHub Actions（测试/构建/覆盖率门禁）。
- CD：CI 成功后自动部署腾讯云 CVM（systemd 重启 + 静态资源同步）。
- 部署产物：后端 Linux 交叉编译二进制、Admin dist、Client H5 dist。
- 备份：每日 02:30 cron（mysqldump + gzip + 7 天保留 + 权限 600）。
- 凭据：`/opt/eqs/.env`（600）EnvironmentFile 加载，备份 cron 从 .env 读取。

## 12. 安全与合规

- 认证授权：JWT HS256 白名单、角色读库、对象级授权、RequireAdmin、禁止自操作。
- 数据保护：AES-256-GCM 敏感字段加密（证书号/经纬度）、手机号脱敏、备份文件 600。
- 接口安全：CORS 白名单（生产域名+同源）、错误信息收敛（生产不泄露）、支付回调验签、上传类型/大小限制。
- 部署加固：systemd 非 root + NoNewPrivileges/ProtectSystem、nginx 安全头、凭据 .env 化。
- 生产启动校验：拒绝弱密钥、必填 DATA_ENCRYPTION_KEY。
