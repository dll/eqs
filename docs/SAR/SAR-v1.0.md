## 8. 遗留问题与改进建议

### 8.1 P0（发布前必须解决）

| 编号 | 问题 | 建议 |
|------|------|------|
| BUG-01 | H5 dev 服务器渲染异常 | 锁定 vue 3.4.21 后 dev 模式仍有 `Cannot assign to read only property '_'` 错误；建议构建模式可用，dev 模式待 uni-app 官方修复或降级到稳定版本 |
| BUG-02 | Go 模块路径不一致 | go.mod 位于 packages/server 但项目根目录无 go.mod；建议统一模块路径 |

### 8.2 P1（发布后尽快解决）

| 编号 | 问题 | 建议 |
|------|------|------|
| IMP-01 | E2E 测试缺失 | 21.5 要求关键用户路径具备 E2E 测试；建议引入 Playwright 或 uni-automator |
| IMP-02 | 微信小程序/iOS/Android 未验证 | 仅验证 H5 构建，三端未做真机验证 |
| IMP-03 | 信用评分动态重算未实现 | 订单完成后未自动触发信用分重算 |
| IMP-04 | 佣金计算未实现 | 合同签署后未计算平台佣金 |
| IMP-05 | 前端 lint 配置缺失 | 缺少 ESLint 配置文件 |

### 8.3 P2（后续版本优化）

| 编号 | 问题 | 建议 |
|------|------|------|
| OPT-01 | Admin chunk 过大 | Element Plus 全量引入导致 chunk >1MB；建议按需引入 |
| OPT-02 | 微信生态集成 | 微信小程序登录、支付等需对接真实接口 |
| OPT-03 | 第三方服务 | 支付/签约/资质核验需对接真实服务商 |
| OPT-04 | 性能监控 | 缺少 APM 监控和告警机制 |
| OPT-05 | 国际化 | 多语言支持待完善 |
