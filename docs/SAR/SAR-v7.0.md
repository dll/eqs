## 5. 后端安全复审（P0 保持 0）

- 认证：JWT HS256 白名单 + 用户状态实时查库 + 角色以数据库为准。
- 授权：对象级授权（订单/项目/争议）+ RequireAdmin + 禁止管理员操作自身。
- 数据：AES-256-GCM 敏感字段加密、手机号脱敏、备份文件 600。
- 接口：CORS 白名单（生产域名+同源）、错误收敛、上传限制、支付回调验签。
- 部署：systemd 非 root + 加固、nginx 安全头、凭据 `/opt/eqs/.env`(600) EnvironmentFile。
- 启动校验：生产拒绝弱密钥、必填 DATA_ENCRYPTION_KEY。
